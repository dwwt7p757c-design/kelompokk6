# KELOMPOK 6 — mobile storefront

Versi ini mengikuti susunan koleksi pada contoh referensi: header gelap iPhone/Safari, grid dua kolom, gambar putih, nama dan harga langsung di bawah produk, serta keranjang dan filter ringkas.

## WhatsApp
Checkout otomatis membuka WhatsApp ke **+62 819-5711-0305** dengan daftar item dan total.

## Kelola katalog
Pilih ikon orang di header untuk membuka pengelola produk. Produk dapat ditambah, diubah, atau dihapus. Semua perubahan tersimpan di localStorage browser. Untuk publish bersama ke semua pengunjung, ekspor JSON dan perbarui array `STARTER_CATALOG` di `assets/js/storefront.js`.

## GitHub Pages
Deploy `main/(root)`. GitHub Pages tidak menjalankan database atau autentikasi server. Versi ini adalah storefront statis yang kompatibel iPhone/Safari dan tidak akan menautkan ke domain Chambre de Lavain.
